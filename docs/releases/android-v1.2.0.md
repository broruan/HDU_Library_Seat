# Android v1.2.0

新增独立 Android 应用 `HDU-Library-Seat-Android.apk`，支持 Android 7.0+ 的 arm64-v8a / x86_64 设备，无需电脑或 Python 安装。

- **账号密码登录**：在应用内的学校官方 HTTPS 页面完成认证，自动接入图书馆会话，无需手动获取 Cookie；应用不保存学校密码。
- **功能与网页共用**：查询选座、座位偏好、使用时段、立即预约、试运行、北京时间定时启动、轮询、停止、任务日志及 SMTP 邮件通知。
- **手机适配**：单列触屏表单、分区导航、固定任务按钮和软键盘适配，覆盖 320 / 390 / 600 像素宽度。
- **后台任务**：前台服务通知显示状态并提供停止入口；预约成功时显示系统通知。
- **取消行为**：停止或退出登录后，不会在查询完成后继续发起新的预约。已经发送至图书馆的请求不能通过关闭应用撤回。

配置保存在应用私有目录，退出登录清除会话并停止任务。定时任务需要联网并允许后台运行；系统强行停止、重启手机或厂商省电限制可能中断任务，需重新打开应用启动。

下载 APK 后按手机提示允许安装。正式版本使用持续保留的签名密钥，普通升级保留应用配置。`SHA256SUMS.txt` 提供下载校验值。Android 单独发布，Windows / Ubuntu 继续使用原发布版本。

构建检查包括共享 Python 测试、Android lint 和 Android 15 模拟器中的安装、面板启动、配置持久化、登录页隔离及正式包启动。验证不使用真实学校账号、不提交真实预约；账号登录、真实座位和邮件投递需用户自己的有效账号与网络。
