# Android v1.2.1

修复 1.2.0 中官方预约页面已登录，点击“完成登录”仍被判定失败，以及重新打开登录页只显示“Seat Index”的问题。

- 登录验证改为读取官方根页面的当前用户信息，独立于座位查询、开放时段和预约时长。
- 登录入口使用官方 SPA 路由，学校认证返回后台控制器地址时自动恢复完整页面，重进登录页也使用同一入口。
- 会话验证沿用登录 WebView 的浏览器标识。网络失败、图书馆响应异常和本机保存失败分别提示，保留当前官方登录页面供重试。
- 登录页增加加载进度和失败重试，继续支持学校官方账号密码和验证码流程。

已安装 1.2.0 的用户，下载 `HDU-Library-Seat-Android.apk` 后**直接覆盖安装**，无需卸载；正式签名保持一致，配置保留。升级后返回面板再打开“账号密码登录”；已有会话可直接验证，需要时重新登录。支持 Android 7.0+ 的 arm64-v8a / x86_64 设备。

修复验证包括闭馆/时段错误下有效会话的响应重放、原生 SPA 路由回归，以及 Android 15 模拟器中的入口、控制器恢复和登录页重复打开。检查不使用真实学校账号、不提交实际预约；实际账号验证仍需由用户在手机上完成。
