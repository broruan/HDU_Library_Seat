# v1.0.2 · 网页面板体验优化

本次更新提升本地查询和预约面板的可读性，并修复手机座位列表和操作提示的显示问题。

## 更新内容

- 将表单整理为登录、使用时段、座位偏好和定时启动；类别 ID、内容 ID 与轮询参数保留在可展开的高级设置中。
- 统一蓝白配色、控件间距与键盘焦点样式，明确开始预约、查询、试运行和停止按钮的主次层级。
- 座位卡片分别显示名称、楼层／内部 ID 和预约状态；已选座位同时显示边框、勾号与文字，状态更易辨认。
- 手机端座位列表随页面完整滚动，修复内部滚动区域导致的列表截断。
- 保存结果和错误提示显示在顶部状态栏，滚动时保持可见，避免遮挡表单和座位图例。

## Windows 免安装版

下载 `HDU-Library-Seat-Windows-x64.exe`，双击即可在默认浏览器打开新版面板，无需安装 Python。适用于 Windows 10 / 11，64 位（x64）。

也可下载 `HDU-Library-Seat-Windows-x64.zip`，解压后运行其中的 exe。压缩包包含相同程序、使用说明和 MIT 许可证。

- 使用期间保留程序窗口；在该窗口按 `Ctrl+C` 或关闭窗口退出。仅关闭浏览器不会停止预约任务。
- 配置保存在 `%LOCALAPPDATA%\HDU-Library-Seat\config.json`。
- 服务仅监听 `127.0.0.1`，启动时自动选择可用端口。
- 使用 `SHA256SUMS.txt` 校验 exe 和 zip 的 SHA-256。

## Ubuntu 安装包

只下载与你的系统版本对应的一个 `.deb`：

| Ubuntu 版本 | 文件 |
| --- | --- |
| 22.04 | `hdu-library-seat_1.0.2-1ubuntu22.04_all.deb` |
| 24.04 | `hdu-library-seat_1.0.2-1ubuntu24.04_all.deb` |
| 26.04 | `hdu-library-seat_1.0.2-1ubuntu26.04_all.deb` |

在下载目录执行以下命令，将文件名替换为所下载的包：

```bash
sudo apt install ./hdu-library-seat_1.0.2-1ubuntu24.04_all.deb
```

安装后从应用菜单打开“杭电图书馆座位助手”，或运行 `hdu-library-seat`。默认浏览器会自动打开面板；保留终端窗口，在终端按 `Ctrl+C` 退出。仅关闭网页不会停止预约任务。

- 使用系统 Python 3，依赖由 apt 安装，无需 pip；`all` 表示纯 Python 包与 CPU 架构无关。
- 配置保存在 `~/.config/hdu-library-seat/config.json`，支持 `XDG_CONFIG_HOME`。
- 运行 `sudo apt remove hdu-library-seat` 卸载，个人配置会保留。
- 使用 `SHA256SUMS-Ubuntu.txt` 校验三个 deb 的 SHA-256。
