# v1.1.0 · 预约成功邮件通知与面板优化

Web 面板启动的预约任务成功后可以通过自己的邮箱发送通知，在手机邮箱 App 接收座位与使用时段提醒。新版面板增加邮件设置、测试邮件和发送状态，并优化预约操作与任务信息的呈现。命令行 `once` / `run` 不发送邮件通知。

## 更新内容

- 新增 SMTP 邮件通知，默认关闭；支持 SSL / TLS 和 STARTTLS，无需增加第三方运行时依赖。
- 邮件设置支持 SMTP 服务器、端口、登录账号、授权码、发件邮箱和收件邮箱；提供“保存配置”和“发送测试邮件”。
- 邮件发送状态与预约结果分别展示，发送失败不会改变已经成功的预约结果。
- 已保存授权码不会在面板重新加载时回填明文；留空保留原值，也可替换或清除。
- 调整面板布局、任务概览、控件间距和状态反馈，兼顾桌面与手机浏览。

## 启用邮件通知

1. 在自己的发件邮箱开启 SMTP 服务，按邮箱服务商要求生成授权码或应用专用密码。
2. 在面板“邮件通知”中填写 SMTP 服务器、登录账号、授权码和收件邮箱；发件邮箱可留空，默认使用登录账号。
3. 选择服务商规定的加密方式和端口：SSL / TLS 通常为 `465`，STARTTLS 通常为 `587`。
4. 打开邮件通知开关，点击“保存配置”，再点击“发送测试邮件”，确认收件箱能够收到邮件。
5. 在手机邮箱 App 登录收件邮箱并开启新邮件提醒，然后开始预约任务。

测试邮件不会提交座位预约。“邮件已提交至邮箱服务器”表示 SMTP 服务器已接受邮件，收件箱投递和手机提醒还取决于邮箱与手机设置。实际发送需要自行提供有效邮箱凭据，发布包不包含发件账号。

SMTP 授权码与 Cookie 保存在本机配置文件中，该文件不属于加密凭据存储。不要提交、分享配置文件或包含凭据的截图、日志。

## Windows 免安装版

下载 `HDU-Library-Seat-Windows-x64.exe`，双击即可在默认浏览器打开新版面板，无需安装 Python。适用于 Windows 10 / 11，64 位（x64）。

也可下载 `HDU-Library-Seat-Windows-x64.zip`，解压后运行其中的 exe。压缩包包含相同程序、使用说明和 MIT 许可证。

- 使用期间保留程序窗口；在该窗口按 `Ctrl+C` 或关闭窗口退出。仅关闭浏览器不会停止预约任务。
- 配置保存在 `%LOCALAPPDATA%\HDU-Library-Seat\config.json`。
- 服务仅监听 `127.0.0.1`，启动时自动选择可用端口。
- 使用 `SHA256SUMS.txt` 校验 exe 和 zip 的 SHA-256。

## Ubuntu 安装包

只下载与你的系统版本对应的一个 `.deb`：

| Ubuntu 版本 | 文件 |
| --- | --- |
| 22.04 | `hdu-library-seat_1.1.0-1ubuntu22.04_all.deb` |
| 24.04 | `hdu-library-seat_1.1.0-1ubuntu24.04_all.deb` |
| 26.04 | `hdu-library-seat_1.1.0-1ubuntu26.04_all.deb` |

在下载目录执行以下命令，将文件名替换为所下载的包：

```bash
sudo apt install ./hdu-library-seat_1.1.0-1ubuntu24.04_all.deb
```

安装后从应用菜单打开“杭电图书馆座位助手”，或运行 `hdu-library-seat`。默认浏览器会自动打开面板；保留终端窗口，在终端按 `Ctrl+C` 退出。仅关闭网页不会停止预约任务。

- 使用系统 Python 3，依赖由 apt 安装，无需 pip；`all` 表示纯 Python 包与 CPU 架构无关。
- 配置保存在 `~/.config/hdu-library-seat/config.json`，支持 `XDG_CONFIG_HOME`。
- 运行 `sudo apt remove hdu-library-seat` 卸载，个人配置会保留。
- 使用 `SHA256SUMS-Ubuntu.txt` 校验三个 deb 的 SHA-256。
